# grades# Задание 6. Табличные данные CSV

## Описание
Программа читает файл `grades.csv`, содержащий имена студентов и их оценки. Данные в каждой строке разделены точкой с запятой (`;`).

Программа вычисляет среднюю оценку всех студентов и выводит имена студентов, получивших оценку 5. Пустые строки пропускаются.

## Подготовка
1. Создайте файл `grades.csv` в папке с программой.
2. **Вставьте в файл `grades.csv` данные о студентах и их оценках.**
3. Каждая строка должна содержать имя студента и оценку, разделённые точкой с запятой (`;`).
4. Сохраните файл.

## Формат файла

Пример содержимого `grades.csv`:

```text
Anna;5
Ivan;4
Maria;5
Petr;3
Olga;4
```

Вы можете заменить пример своими данными.

## Как запустить
1. Подготовьте файл `grades.csv` с данными о студентах.
2. Запустите Python-программу.
3. Программа выведет имена студентов, получивших оценку 5.
4. Затем программа рассчитает и выведет среднюю оценку всех студентов.

## Пример результата

```text
Anna
Maria
Средняя оценка: 4.2
```

## Важно
- Файл `grades.csv` должен находиться в той же папке, что и программа.
- Перед запуском необходимо самостоятельно заполнить файл данными.
- Имя и оценка должны быть разделены точкой с запятой (`;`).
- Оценка должна быть целым числом.
- Пустые строки пропускаются и не учитываются при вычислении среднего значения.
- Если в файле нет оценок, программа выводит сообщение `Нет оценок`.
